# UmaDesktop 3.13.0：Include 少量角色时补足六只

在“角色与地面”页选择 Include 并应用：

- 选择 1～5 个有效角色：允许同一角色以不同服装同时出现，自动逐步补位到最多六只。例如只选特别周，就会逐步生成最多六只、服装互不相同的特别周。
- 每次补位优先从当前数量较少的选中角色中抽取。已有角色会继续原本的活动与轮换；新增名额逐步分配，不会因增加勾选项立即重排全场。
- 同名角色的“角色＋服装”组合在场上保持唯一，包含仍在入场或退场的实例。随机换装会避开同名实例正在使用的服装；手动指定已占用服装会提示并保留原模型。
- 服装继续按胜负服 50%、校服/训练服 30%、其余 20% 抽取；某类服装全部被占用时，在其他可用类别中按权重重新抽取。若可用服装总量不足，最多只会生成可用的不同服装数量。
- Include 选满六个及以上角色、全随机、Exclude：继续保持同名角色不重复。切换模式后多余实例会走向出口，完整离场后再补位。
- 空 Include 不自动生成角色。此前指定手动上场的角色仍按原规则保留，可单独点击退场。

控制面板的在场角色列表显示“角色名 · #实例编号 · 服装名 [服装编号]”。换装后保留该实例的选择位置，不会跳到另一只同名模型。指定动作、换装和退场只作用于选中的实例。

允许重复的角色也可使用“指定角色上场”：满六只时仍排队，等空位后以未占用的服装进入。原有入退场渐变、地面与拖拽、动作与表情规则保持原逻辑。低功耗启动的自动模型数量设置仍会生效；硬上限始终为六只。

本轮实测：单角色六种服装实际渲染、两个角色各三只、五个角色补成六只、六角色恢复同名限制、空 Include、全随机与 Exclude，以及独立换装、动作、指定退场和重复角色排队上场。测试后恢复用户原配置，不自动改变你的 Include 名单。

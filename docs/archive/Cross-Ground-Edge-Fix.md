# 跨地面拖拽后的右边缘回弹修复 · 3.10.3

## 现场确认

读取正在运行的美浦波旁（1026、服装 00、run03_loop）状态，确认动画持续前进，但模型在屏幕右边缘附近来回移动，地面通道透明度约 0.52～0.89。状态记录保存在 v17/live-stuck-before.json。

## 原因与修复

3.10.2 为避免鞋底出界，把抬脚后鞋子的画面范围也限制在地面四边形内。抬脚包含竖直高度，不属于水平占地；在窄斜面上，这会每迈一步就把整个模型推回去。现在约束双鞋在地面上的水平投影，保留抬脚、脚踝和跳跃的自然高度。此前的实际鞋底接触高度校准继续使用。

边界修正位置时，如果原移动目标不可达，会改走安全区域内部，避免持续顶向同一条边。目标和位置都在同一块地面的安全范围内计算。窄地面的额外等比适配倍率在该地面上保持稳定，不再每帧先扩大再缩小；更换地面或重建尺寸时重新评估。

活动中和走向出口时始终保持通道不透明，只有实际入场、穿过出口时使用边缘淡入淡出。拖动期间与松开后仍按原约定暂停／恢复动画，离场中的角色跨地面拖动后仍使用目标地面的出口。

## 验证

在当前保存的两块地面、150% 尺寸下，用美浦波旁 00 服装反复从另一块地面拖到屏幕右边缘之外。分别持续播放 run03_loop、run00_loop、walk01_loop 和 walk02_loop，检查松开后持续移动、透明度、双鞋地面投影和桌面窗口层级；另检查离场途中跨地面拖动后仍能离开。

测试使用程序自身的测试指针事件队列，不向系统注入鼠标输入；原生鼠标钩子另做回归。详细结果见 edge-drag-report.json、edge-drag-observations.json 和配套透明渲染图。几何测试增加重复边缘恢复及离场检查，包含 42,165 项断言。

旧的 3.10.2 验证记录只检查了短时间边缘姿势和拖动释放，未覆盖原奔跑片段长时间循环。此版本加入持续步态验证，避免专属动作切换掩盖卡边问题。当前保存的地面、入口出口、角色名单和大小设置保留。

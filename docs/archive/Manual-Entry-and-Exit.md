# 指定角色上下场与进出场渐变 · 3.11.0

## 操作

控制面板上方仍选择当前场上的角色，点击“立即退场”，该角色会中断当前专属动作或双人互动，直接向所在三维地面的出口移动，穿过出口并渐隐后消失。默认地面或二维直线使用对应边缘／端点。其他角色继续活动。退出命令如果指向已离场的旧角色，不会误操作另一只。通知区域右键菜单也有选中角色退场入口。

“指定角色上场”的下拉框提供完整可用角色目录。选择后点击按钮，有空位就从随机地面的入口进入；场上已有六只（包含入场、退场中的角色）则排队，直到有角色完整离场释放空位。排队不提前赶走任何角色。多名请求按顺序处理，同名角色已经排队时不重复添加。3.13.0 起，Include 只选 1～5 个有效角色时，可以让已在场的选中角色以其他服装再次上场；其他模式仍拒绝重复同名。衣服仍按原有服装概率随机选择。

成功创建一名指定角色后，下一次随机出场／满员轮换的计时从头开始。只是点击排队不会重置计时；排队角色获得空位后优先上场，不需要再等待随机补位的空档。如果尚未满员，手动上场可以利用空位，不必等待另一名正在离场的角色；该离场稍后完成也不会覆盖刚重置的计时。

手动选择不改变 Include／Exclude 名单，也不会因为不在随机名单内就立刻被移走。手动上场的硬上限为六只；MaxActors／低功耗档继续控制自动随机补位数量。手动选择的角色仍参与后续正常 FIFO 轮换。手动队列只保留在本次运行中，重启后清空。

全局暂停、编辑地面或桌面完全被遮挡时，队列保留，恢复后再入场；此时退场指令也会等待恢复后继续移动。

## 渐变

入场与退场都使用平滑透明度变化；三维通道及二维端点在必要时降低穿越速度，给淡化保留 FadeSeconds 对应的可见过渡，避免高速角色一帧穿过窄通道。动画速度按实际移动距离同步调整。默认 FadeSeconds 为 0.5 秒，窄通道外的行走路程不受这个时长限制。默认屏幕底边也会随进入／离开边缘渐变。

正常活动或只是靠近普通地面边缘时保持不透明，保留 3.10.3 的卡边修复。原有换装渐变继续使用。

## 验证

控制面板独立自测验证实际按钮处理、角色目录、队列顺序文字和控件布局，并生成 controller-preview.png。Unity 集成覆盖空位上场、特殊动作中退场、旧选择安全、暂停排队、另一角色离场期间的上场及计时保留、默认／二维／三维渐变，以及真实满六只后的自然轮换与两名请求 FIFO 补位。记录见 manual-entries-report.json。

测试通过本地命令协议与自身测试事件执行，不代表实体鼠标操作验收。原生点击回调、已有拖拽、右边缘恢复、地面比例、鞋底投影和六角色轮换另行回归。游戏数据不包含在发布包中，保存的地面和其他设置保留。

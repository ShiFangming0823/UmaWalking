# UmaDesktop 3.12.0：性能、数据与诊断设置

控制面板新增“设置与诊断”标签页。已有角色、服装、地面、排队上场等操作保留在“角色与地面”页。

## 性能

- 帧率：15 / 30 / 60 / 120 FPS，默认 30。选择后即时生效并保存，下次启动沿用。
- 抗锯齿：开启使用 4× MSAA + FXAA；关闭时两者都关闭。切换无需重载角色或重置动作。
- 帧率表示目标上限，实际帧率仍取决于电脑和同时显示的模型数量。低性能电脑建议先选 15 或 30，再按需要关闭抗锯齿。
- 桌面完全被遮挡时仍自动暂停并降至低频；这些设置不会取消原有暂停行为。

## 诊断文本

点击“拷贝当前状态与日志”，将文本粘贴到 issue，并补充预期效果、实际情况和复现步骤。文本包含：

- 版本、程序校验值、系统及显卡、目标与当前帧率、抗锯齿、当前暂停原因。
- 保存的设置、二维/三维地面、角色/服装/动作/表情、入退场和队列状态。
- 资源索引校验值、可用角色及服装数、精简数据标识、提取状态。
- 最近事件及运行日志，每个日志最多 64 KiB。

默认替换本机路径与用户名；提交前仍请自行检查内容。不会自动上传、创建 issue 或发送任何消息。剪贴板被其他程序占用时，会将报告保存到 DesktopLogs/diagnostic-report.txt。

## 数据目录

点击“选择数据目录…”，选择同时包含 `meta`、`master/master.mdb`、`dat` 的目录。必须选这一层目录，不能只选 dat。保存成功后程序自动重启，并保留尺寸、地面和角色选择等设置。目录无效时保留原配置。如果首次启动没有数据，控制面板会自动显示；也可从任务栏重新打开，设置正确目录。

## 精简提取

1. 先选择可正常加载的完整数据目录。
2. 点击“提取迷你角色素材…”，选择一个空的目标目录。目标目录必须与原目录分开，不能互相嵌套，也不能使用符号链接或目录联接。
3. 程序保留压缩素材，并复制所有现有迷你模型、所有迷你服装、动作、表情、材质/纹理/物理及递归依赖，同时保留必要的资源和角色数据库。不会导出成通用模型格式。
4. 每个文件复制时计算 SHA-256，再读回目标文件校验。原索引在复制前后也必须一致。期间可以取消；取消或失败时不会切换目录或删除原包，未完成的目录会留下标记，请重新选择空目录。
5. 校验通过后自动切换至精简目录并重启；核对精简目录可用角色与服装数量后，弹出是否删除原数据的对话框，默认保留。
6. 只有明确选择“是”后，才会再次验证目标文件并删除原目录内的 `dat`、`meta`、`master/master.mdb`。其他文件保留。删除对象和完整路径会写在确认对话框里。原目录之后不能供完整游戏使用；新模型更新需要重新下载全量包并重新提取。

建议完成确认前退出游戏，避免游戏更新或占用原数据。可选择保留原包；确认提示仅显示一次，之后仍可自行管理原目录。

本机验证：原目录 52,756,293,683 字节（约 49.13 GiB）；精简素材与索引 647,052,388 字节（约 617 MiB / 0.60 GiB），11,658 个文件，保留 136 个角色、4080 种服装组合。实际空间会随游戏版本变化。验证了精简目录独立启动，并抽测 8 个角色的胜负服、通用服装、跑步、专属动作和表情。此结果不代表逐一播放过全部服装或动作。

这轮测试没有删除你的原全量数据，也没有改变你正常使用的数据目录。发布压缩包不包含游戏素材或测试用的精简数据。

## 语言

支持简体中文、日本語、English；首次启动按 Windows 用户界面语言选择，中文选中文、日文选日文，其余选英文。之后手动选择即时生效并保存。3.14.0 起，当前 136 个角色的名称随界面语言切换；支持中日英名称搜索。服装名称保留数据索引中的日语原文，Windows 文件夹选择框及系统对话框的按钮遵循系统语言。

## 验证范围

本版检查覆盖实时性能设置及限速、暂停时切换抗锯齿、语言保存、无效目录恢复、自动重启、精简素材独立运行、诊断脱敏与复制/删除保护，并回归了拖拽、鼠标路由及六角色轮换。界面预览来自程序自己的渲染；没有模拟实际鼠标操作，也没有自动确认删除真实游戏数据。

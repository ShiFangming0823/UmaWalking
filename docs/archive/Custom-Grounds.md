# 自定义地面 · 3.9.1

在主屏幕上显示桌面，左键托盘图标打开控制面板。在“地面”一行选择“二维直线”或“三维四点地面”，再点击“绘制 / 编辑地面”。控制面板会隐藏，出现覆盖主屏幕的半透明绘制画布和可拖动的工具条。壁纸会透过画布显示；其他应用窗口如果仍在桌面前方，也会透出来，因此建议先显示桌面再打开面板。

## 二维直线

依次点击直线的两个端点，点击“保存并应用”。角色沿这条直线往返，脚下位置随直线的斜率变化，从端点进入、从端点退出。可以拖动已有端点，或点击“重画直线”重新绘制。角色尺寸保持平面模式的大小。

## 三维四点地面

1. 按“远左 → 远右 → 近右 → 近左”的顺序，点击地面的四个角点。四边形必须为凸形，边不能交叉，也不能把三个点放在同一条直线上。
2. 画完四点会自动进入入口设置。在同一条边上点击两个位置，二者之间的绿色区段就是入口宽度。
3. 接着自动进入出口设置。同样在一条边上点击两次，橙色区段就是出口。入口和出口可以位于不同边，也可以部分或全部重合；重合时出口使用橙色虚线覆盖显示。
4. 如需更多地面，点击“添加地面”，重复上述步骤。最多三块；用下拉框选择编辑哪一块，可以删除多余的地面。每块都需要完整的四点、入口、出口。
5. 点击“保存并应用”。角色每次出场都会等概率选择一块地面，在所选入口宽度内随机选择位置，进入后在该地面内走动，到退场时前往该地面的出口。

已有角点可以拖动，入口和出口会随所在边一起移动。工具条可以拖走，避免遮住绘制位置。“设置入口”“设置出口”可分别重新指定通道。“重画四点”会在四点完成后要求重新选择入口、出口。右键撤销尚未完成的一组点击，Esc 或“取消”放弃本轮修改；Enter 仅在地面有效时保存。绘制过程中角色和出入场计时暂停，结束编辑后恢复此前的手动暂停状态。

运行时不显示地面填色、线条或编辑把手，只显示模型。模型的脚点按四点透视映射移动，远处变小、近处变大；身体由独立相机保持原始比例、等比例缩放，地面再狭长或倾斜也不会把身体拉扁或斜切。身体朝向按地面路径的屏幕方向改变，前后模型按脚点的屏幕高度排序。入口、出口处有淡入淡出，避免在地面范围外突然出现。

各块地面共用原有的最多六只、名称不重复与先进先出调度规则。换装保留所在的地面与行进位置。双人互动只允许同一地面且站位接近的角色触发，边缘没有足够站位时跳过。自动专属动作仍需检查周围空间，鼠标点击立即触发的例外规则保留。

点击“恢复屏幕底部”可回到原来的屏幕底部直线。地面保存在程序目录的 DesktopSettings.json 的 Ground 字段中，重启后继续使用；坐标按主屏幕宽高归一化，分辨率变化后按比例调整。修改地面并应用时，当前角色会重新从配置的入口进入，不必重新加载角色资源。

## 当前范围

本版支持主屏幕上的直线，以及最多三块凸四边形地面；不支持凹多边形、曲面、楼梯、壁纸物体遮挡或不同地面之间换层。四点确定的是平面的屏幕投影，透视过强或面积过小的配置会提示重新绘制。远边和近边画得一样宽时，不产生明显的远近缩放。不同地面可相互重叠，模型仍按屏幕前后顺序合成。

地面编辑器无需安装额外依赖，和现有控制面板一起发布。半透明窗口在编辑期间显示在其他窗口上方；保存后，角色继续作为 Explorer 桌面子窗口运行，保留桌面遮挡自动暂停及 Alt+Tab、FancyZones 兼容逻辑。

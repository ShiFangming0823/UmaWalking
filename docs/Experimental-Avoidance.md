# UmaWalking 1.0.0：三维地面角色避让（实验性）

在控制面板的“设置与诊断”中勾选“三维地面角色避让（实验性）”。新配置默认关闭，修改后即时生效并保存，无需重新加载角色。关闭后恢复原有移动方式。二维直线和默认屏幕底边不启用新避让。

## 运行方式

- 预测同一块三维地面上角色即将发生的占地碰撞，优先尝试侧向绕行；空间不足时可转向或暂时让行。不是等穿过以后再把模型弹开。
- 绕行位置受原地面和鞋部占地边界约束，不会把角色推到另一块地面或地面之外。不同地面的角色互不阻挡。
- 体型、模型大小滑块和地面透视会影响避让距离。判断使用水平占地，不使用角色窗口整张透明区域。远近不同的角色在画面中有局部遮挡，未必表示碰撞。
- 鼠标按住或播放专属动作的角色作为静止障碍；仍可以点击立即播放专属动作。手动拖动本身不受其他角色限制；若放下时重叠，后续移动会尝试连续分离，不会瞬移弹开。
- 原有双人互动保留，符合相遇条件时先判断互动；已配对的两位角色按原演出站位，其他角色仍会避开。
- 退场仍前往原出口，临时绕行不会替换出口或重置入退场阶段。入口拥挤时，尚未进入地面的角色可沿入口方向后退让行，避免堵住离场角色。

若地面过窄、角色过大，或入口处空间不足，无法保证所有角色都持续通行；它们可能转向或等待。可以减小模型，扩大地面，或者关闭此开关。

## 诊断

“拷贝当前状态与日志”包含 `avoid3DCollisions` 开关，以及每只角色的 `avoidanceState`（off / clear / detour / reverse / yield / stationary）、占地半径和避让/转向计数，便于反馈不合理路线。

纯算法六角色密集交叉的本机测量平均每次约 0.22 ms；这是规划器微基准，不包括渲染、窗口合成或加载，不能代表低配电脑的总资源占用。

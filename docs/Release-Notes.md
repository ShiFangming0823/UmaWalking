# UmaWalking v1.0.0

## 简体中文

首个公开版本：实时迷你马娘桌宠，支持随机角色／服装／动作、自定义地面、拖拽、手动入退场、表情、性能与语言设置。新增版本显示、GitHub问题入口、可选开机启动、正式版更新提醒和跨版本配置保留。优化表情贴图的边缘采样与近肤色压缩色差。

请自行从官方DMM客户端取得游戏数据。程序不附带游戏模型、动作或提取包。下载Windows-x64 ZIP并完整解压。首次从旧开发版移至新文件夹前，请复制旧DesktopSettings.json；1.0.0以后更新会自动继承用户配置。

## English

First public release: real-time mini-Umamusume desktop companions with random characters/outfits/motions, custom grounds, dragging, manual entry/exit, expressions, performance and language settings. Adds version display, issue links, optional Windows startup, stable-release update notices and persistent settings across upgrades. Improves expression-atlas edge sampling and near-skin compression colors.

Obtain game data through the official DMM client. No game models, motions or extracted pack are bundled. Download and fully extract the Windows-x64 ZIP. For a first new-folder upgrade from a development build, copy the old DesktopSettings.json before launching; upgrades after 1.0.0 inherit the user profile.

## 日本語

初の公開版。ミニウマ娘のランダム表示、衣装・動作・表情、地面編集、ドラッグ、指定入退場、描画・言語設定に対応します。版表示、問題報告リンク、任意のWindows自動起動、正式版更新通知、更新時の設定引き継ぎを追加しました。表情アトラス端のサンプリングと肌色に近い圧縮色差を改善しました。

ゲームデータは公式DMMクライアントから各自取得してください。モデル・モーション・抽出パックは同梱しません。Windows-x64 ZIPをすべて展開してください。開発版から新フォルダーへ初めて移行する場合は起動前に旧DesktopSettings.jsonをコピーし、1.0.0以後はユーザー設定を引き継ぎます。

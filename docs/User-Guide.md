# UmaWalking user guide

The maintained user guide is the trilingual [root README](../README.md):

- [简体中文](../README.md#zh-cn)
- [English](../README.md#english)
- [日本語](../README.md#japanese)

Start with `Launch-UmaWalking.cmd`, then select your official game's `Persistent` directory in Settings & Diagnostics. Keep every runtime sibling file together. Downloading only the EXE is insufficient.

Current defaults: 30 FPS, six actors, antialiasing enabled, experimental 3D avoidance disabled, random first actor, system UI language. The actor cap can be set from one to ten. A lower cap removes excess actors through their normal exit, so the display can temporarily exceed a newly lowered limit during departures.

Historical implementation notes are kept in [archive](archive/Legacy-User-Guide.md); the root README takes precedence where older notes differ.
